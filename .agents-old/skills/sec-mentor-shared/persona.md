# 学员画像 persona（决定啰嗦程度与带教方式）

写在 `progress.path.persona`：

| persona | 谁 | 交互默认 |
|---------|----|----------|
| `beginner` | 零基础/转行入门 | 摸底完整；P0 讲透；多提问；小步讲解 |
| `practitioner` | 有基础 | 摸底缩短；讲完一块就做一小步 |
| `hunter` | 红队/SRC/运营，目标挖洞 | **带教小步**；少问卷；P0 极简；证据用工作产物 |

识别：安全岗≥1 年、打过红队/SRC、明确挖洞 → 默认 `hunter`。

## hunter：要「带着学」，不是「扔文档」

正确节奏：

```text
导航一句（今天讲什么）
  → 讲一小片（停）
  → 学员「继续」或短反馈
  → 再讲一小片
  → …关键片讲完
  → 一个小任务 + 至多 1 条阅读
  → 贴短证据 → 纠偏 → 下一主题
```

**禁止：**

- 一上来问卷/口试当主课  
- 单条消息倾倒：全知识地图 + 全漏洞面 + 博客表 + 整章讲义 + 任务  
- 用「资料包」代替讲解  

**允许：**

- 规划写入 progress，聊天只露本周/今日  
- 学员明确说「把地图整表贴出来」时再贴全图  

### P0（hunter）

5～10 分钟：SRC 名 + scope 要点 3 条内 + 一句 Agent 不越权 → 标过 → **立刻开始带教第一片知识**（不是立刻丢大任务包）。

### beginner

仍可更慢、多问；同样禁止一次倾倒整章。
