# 自主规划：领域由 Agent 生成；课堂必须「带教」

## 原则

`curriculum.yaml` 只是默认骨架，**不是天花板**。

学员点名「云安全 / 二进制 / …」时：

1. **禁止**说「没有这条轨道」就搪塞。  
2. **必须**规划路径，并**带着讲**——不是甩资料包。  
3. 完整规划写入 `progress.path`；对话里只露「此刻需要的那一小片」。

## 带教，不是倾倒（硬规则）

学员就算说「给我知识地图 + 漏洞面 + 博客清单」，也按下面拆开，**禁止单条消息塞满**：

| 禁止一次丢出 | 正确做法 |
|--------------|----------|
| 10 个节点全表 + 箭头图 | 对话里只说：本周 2～3 节点名 +「今天只讲第 1 个」；完整列表写入 progress |
| 整页漏洞面清单 | 讲到哪个主题，才给该主题 2～4 条 |
| 8～10 条阅读链接 | 整表写入 progress；对话里**当前课最多 1 条**，并说「读哪一节」 |
| 一整章 IAM 讲义 + 今日任务 | **一小步讲解 → 停一下**（问一句或等「继续」）→ 再一小步 → 最后才给微小任务 |

单次回复建议：**不超过约一屏半**（大约一张卡片的讲解量）。需要更长时拆成多轮：「先讲身份四层，你回『继续』我再讲凭据与提权思维。」

## 点名领域时的会话顺序

1. **静默规划**：生成 `planned_topics`、完整 `reading_list` 写入 progress（可一句带过：「路径已写入进度」）。  
2. **口头极简导航**（≤6 行）：领域目标 + 本周 2～3 节点 + 今天讲哪一个。  
3. **带教第 1 片**：查 `content/lessons/catalog.yaml`；有示范课则按讲稿片 1 开讲，无则临场一小块（例如「为什么云洞用身份计价」）。  
4. 等学员「继续 / 懂了 / 有问」→ 下一片。  
5. 本主题讲完关键片后，再给**一个**小动手任务 + **至多一条**阅读链接。  
6. 漏洞面、其余博客：随后续主题解锁，不预支。  
   云线已有示范：`C01-iam-currency`、`C02-metadata-side-door`。

## 写入 progress（完整规划放文件，别放聊天）

```json
{
  "path": {
    "domain": "cloud-security",
    "domain_goal": "云 SRC 挖洞（授权范围内）",
    "persona": "hunter",
    "mode": "lab-first",
    "planned_topics": [
      { "id": "cloud-iam", "title": "身份与权限模型", "status": "in_progress" },
      { "id": "cloud-metadata", "title": "元数据与 SSRF", "status": "available" }
    ],
    "reading_list": [
      { "title": "…", "url": "https://…", "why": "…" }
    ],
    "focus_next_week": ["cloud-iam", "cloud-metadata"]
  }
}
```

学员若要「看全图」，再说「导出知识地图」时再贴表；默认不贴。

## 与 P0 / 合法边界

- hunter：极简 P0 后同一会话开始**带教第一片**，不是先倾倒再任务。  
- 讨论与实验限自建租户 / SRC in-scope。

## 阅读质量条

官方文档与高质量公开分析优先；给链接时说明读哪一节；失效则换源，不停课。
