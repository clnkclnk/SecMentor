# Lab: path-traversal

## 目的

理解「用户输入拼进文件路径」如何变成任意文件读取。对应 `file-download`。

## 启动

```bash
cd labs/path-traversal
docker compose up -d
```

打开：`http://127.0.0.1:18081/`  
按镜像说明完成初始化（若有创建数据库按钮则点一次）。默认账号以页面/镜像说明为准（常见为 `admin` / `password`，以实际为准）。

## 任务

1. 将安全级别调到 Low（若界面提供）。  
2. 进入与 **File Inclusion** 或文件读取相关的练习页（名称随镜像界面）。  
3. 尝试通过修改参数读取本可越权访问的资源（仅此容器内）。  
4. 用自己的话写下：输入如何影响服务端打开的文件路径；防御思路（规范化路径/白名单）。

若界面与上述不完全一致：以「文件路径被用户参数影响」为准，完成等价任务，并记录实际菜单路径。

## 交给导师

- 你用的 URL/参数形态（可打码）  
- 观察到的现象  
- 一句话原理 + 一句话防御  

## 清理

```bash
docker compose down
```
