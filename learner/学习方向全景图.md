## 推荐学习顺序（建议）

按"补齐 Web 漏洞面 → Web CTF 综合 → SRC 实战"的节奏：

1. **B 类选 2~3 个**（推荐 XSS 进阶 + 文件上传 + 越权/逻辑漏洞）
2. **C 类选 1~2 个**（推荐 JWT + 越权 IDOR，SRC 高频）
3. **Web CTF 综合挑战**（把所有 Web 漏洞串起来练）
4. **SRC 仿真靶场**（真实业务站，侦察+挖洞+写报告）
5. **真实 SRC**（货拉拉 8/16 活动）
6. 视兴趣决定是否进入 D 类新赛道
