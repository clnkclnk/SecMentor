# 示范小课（可教内容包）

这里是 SecMentor 的**讲稿**，不是又一份操作规程。

参考 [sqlsec 课程站](https://course.sqlsec.com/) 的思路：**先建立心智模型 → 再动手验证 → 配套可读材料**；语气偏寓教于乐（江湖比喻），但每片只讲一个点，停下来等人说「继续」。

## Agent 怎么用

1. 打开 [`catalog.yaml`](./catalog.yaml)，用当前 `topic_id` / 规划关键词匹配课。  
2. 打开对应 `.md`，按 [`_format.md`](./_format.md)：**只讲钩子 + 当前片**，禁止一次贴完全文。  
3. 片讲完再给「今日微任务」；过关后再写 `progress.json` 证据。  
4. 没有命中示范课时：临场也要按同一「片」结构讲；讲得好可沉淀成新文件并登记 catalog。

## 和 labs / curriculum 的关系

- `curriculum.yaml`：默认 Web 地图（骨架）  
- `content/lessons/`：怎么讲（课文）  
- `labs/`：可选动手示例，**不硬绑定**；课里的 `lab_hint` 可忽略并换成公开靶场
