## 钩子

想象一座客栈：门口挂牌、账房记账、厨房出菜、后院存粮。  
黑客很少「一掌劈开山门」——多半是发现哪扇窗没关、哪把钥匙借错人、哪道菜里被人塞了纸条。  
今天这课不教你拆客栈，只教你：**入侵故事通常长什么样**，以及我们练功只在「练武场」（合法靶场 / 授权范围）里打。

（停：等学员说「继续」）

## 片 1 · 一条常见入侵链（心智模型）

多数 Web 入侵可以压成四步（记故事，别背名词）：

1. **看见** — 知道客栈开在哪、卖什么（信息收集：域名、技术栈、入口）  
2. **试门** — 找没关严的窗（漏洞点：参数、上传、逻辑）  
3. **进院** — 拿到能做坏事的凭证或命令能力（会话、文件、命令执行）  
4. **搬粮** — 拿数据或留下后门（目标达成）

你以后学的每一个专题（注入、越权、配置错误……）都是在某一步上「把门敲得更响」。

（停：等学员说「继续」）

## 片 2 · 脆弱应用从哪来

脆弱不是魔法，常见几类：

- **信任了不该信的输入**（用户输入直接进数据库 / 命令 / 页面）  
- **钥匙管得松**（默认口令、密钥进仓库、权限过大）  
- **逻辑以为用户很乖**（少校验一步就变成越权）  
- **旧组件带着旧伤**（没打补丁的框架 / 中间件）

发现漏洞的方式也分档：扫一眼配置 → 手工跟业务逻辑 → 读代码找信任边界。我们后面会从「看得见的 HTTP」开始练。

（停：等学员说「继续」）

## 片 3 · 练武场规矩（30 秒说清）

- **练**：公开靶场、自己搭的环境、SRC/项目**写明的 scope**  
- **不练**：没授权的真实站、同学公司内网、随机扫别人的云  
- 目标是练「看见 → 验证 → 讲清楚」，不是刷「打穿多少站」的虚荣数字
